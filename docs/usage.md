# 使用说明

各功能窗口的详细操作语义与口径。总览与快速上手见 `README.md`；语言参考见 `docs/script_language.md`；架构见 `docs/architecture.md`。

## 命令行（无头模式）

```
roxy-can                                  开窗口（默认）
roxy-can --replay <log.asc|blf> [...]     回放日志，不开窗口
roxy-can --project <p.rxproj> [...]       无头仿真整个工程
roxy-can --check-script <f.rxcan> [...]    校验节点脚本（flag 可重复）
roxy-can --convert <in.log> <out.asc>     BLF/ASC 转存为 ASC
roxy-can --kvaser-probe                   列出 canlib 可见的 Kvaser 通道
roxy-can -h                               完整帮助
```

- **`--replay`**：按日志时间轴回放；`--speed <n>` 倍速（默认 1.0），`--duration <s>` 到时即停（默认跑到日志末尾），`--stats <csv>` 结束后导出消息统计。回放自动静音同 ID 的发生器条目，不会两路混流。
- **`--project`**：无头仿真保存的工程——生成器与脚本节点按工程里保存的**条目开关**上线，且照常受**角色闸**（节点角色须为 `Simulated` 才真正发车；GUI 与 CLI 同一语义）。必须给 `--duration`，否则仿真没有终点。
- **`--profile <名>`**：叠加 `<工程目录>/profiles/<名>.toml` 里的**角色覆盖与硬件映射**，需配合 `--project`——同一套工程在 simulation / bench / CI 间零修改切换。角色词汇与工程一致（`Simulated` / `Monitor` / `Absent`）；`[[hw]]` 声明"哪条总线接哪个 Kvaser 通道"（波特率取总线自己的设置），**全量生效**：未列出的总线应用档案时解挂。GUI Network 窗口顶部的 Profile 行与此同源。Profile 只改角色，**不碰**生成器条目的 On 开关；写了不存在的总线 / 节点 / 角色词则**整份拒绝**（半套覆盖比没有更难排查），运行中止在任何发车之前；硬件打不开（适配器不在、驱动缺失）进状态行但不中止——角色覆盖独立成立。格式：
  ```toml
  # profiles/bench.toml —— 被测件是真硬件，其余全模拟
  description = "bench rig"

  [[node]]
  bus = "Powertrain"
  node = "EngineECU"
  role = "Simulated"

  [[hw]]          # 可选：硬件映射（全量声明）
  bus = "Powertrain"
  channel = 0     # Kvaser 通道号
  ```
- **`--stats`**：结束时写出消息统计 CSV（bus, id, name, count, 周期 Min/Avg/Max, 长度, Flags）。
- **`--check-script`**：编译 `.rxcan` 节点脚本，全部通过退出码 0；任一失败退出码非 0 并列出 `line N:M` 错误。通过时顺带打印**静态响应映射**（`on A` 经哪个定时器 → 回哪个报文）与**发送 / 接收集**——CI 门禁之外，也是一份脚本行为的自动摘要。适合放进 CI 或保存前钩子。配合 **`--dbc <路径>`**（可重复，按序合并，重名先到先得）与 **`--node <名>`**（脚本扮演的 DBC 节点名）时，GUI 节点启动时的同一套装配检查在无头侧照跑：信号引用、发送集对照、反向漏实现、`set_sig` 字面量范围（系统变量检查需要管理器状态，仅 GUI 侧）。`[check]` / `[info]` 只进报告不改退出码——门禁的硬失败仍是编译错误。
- release 版无控制台窗口：从终端启动时会自动认领父控制台输出报告。
- **边界**：回放模式不支持录制——核心有意在回放启动时丢弃录制状态（录回放只会复刻日志）。

## 仿真节点（脚本编辑器）

- 脚本节点在 **Network** 视图的节点详情里创建："+ 脚本节点"（**绑定**到该 DBC 节点，总线跟随节点）。创建后自动弹出该节点的**独立脚本编辑器**（标题"脚本 · 节点名"，可多开）。树形拓扑里节点下面挂的就是它的脚本叶，点击即开编辑器。
- **绑定与角色闸**：脚本一律**依附于一个 DBC 节点**（Network 节点详情"+ 脚本节点"创建，绑定随工程保存）——所属节点角色不是"模拟"时，脚本同样**不发车**（`on start` / 定时器 / 事件发帧全被闸住），与生成器条目同一规则。旧工程的未绑定脚本在库加载时**自动收养**到该总线第一个库节点下。
- 编辑器内：改名、绑定显示（`节点 X · 总线 Y`，只读——脚本依附节点，没有总线选择）、**经硬件**开关（该总线已挂接时出现）、**运行**开关、源码编辑、**Apply** 下发（测量中即时重编译重启该节点）、**保存/加载 `.rxcan`**、节点日志。点 Network 树里的脚本叶（或节点详情脚本列表的名字）可再次打开。
- **侧栏四个 tab**：**函数**（可点击插入的模板 + 本节点自己的 DBC 报文/信号，插入落在光标处、有选区则替换）；**大纲**（草稿里每个处理器/函数一行，带行号，容忍没写完的源码）；**收发**（静态事实表：发送集按 DBC 归属标 `*` 本节点 / `!` 他节点 / `-` 不在库，接收集含 `*` 通配，访问的系统变量，响应映射——事件 → 武装的单次定时器 → 回复帧）；**SysVar**（已定义的系统变量，一键插入读/写模板）。事实按草稿内容缓存，敲键才重算。
- **源码区**（基于 ImGuiColorTextEdit 的语法编辑器控件）：Lua 语法的实着色（关键字/数字/字符串/注释），行号栏、空格浅色圆点、括号匹配、自动缩进、撤销/重做与查找替换（编辑器自带快捷键）；编译出错的行整行红底加行号红条标出（悬停可见错误全文，另见大纲/收发 tab 顶部与节点日志）。字体按显示密度动态光栅化，高 DPI 下依然锐利。
- **装配层检查**（Apply / 测量启动时进节点日志与 Write 窗口）：`sig` / `set_sig` 引用的信号须在 DBC 中；发送集对照 DBC 发送者声明（发了别家/不在库的报文 → `[check]`）；**反向漏实现**——DBC 声明本节点发送、脚本从不发送的报文 → `[info]`（生成器代发是常态，通配脚本豁免）；`set_sig` 字面量值超出 DBC 声明范围 → `[check]`（`min==max` 视为未声明界限）；引用未定义的系统变量 → `[check]`。
- 事件：`on start`（测量启动一次）、`on message <id>`（含 `*` 通配收所有数据帧）、`on extended message <id>`（显式扩展帧，数值可 ≤ 0x7FF）、`on errorFrame`（错误帧）、`on timer <ms>`（周期）、`on timer "名"`（一次性，`set_timer("名", ms)` 武装、`cancel_timer("名")` 取消，任意回调可调）。
- 节点会收到**自己发出的帧**：在通配/同 ID 处理器里无条件发帧会自激成环，务必用 `frame_id()` 过滤。
- 节点出错（编译或运行时）即**熔断停跑**，日志留原因；重新 Apply 或重启测量恢复。周期定时器错过的时间点收敛为一次触发，不补偿堆积。
- `print(...)` 输出到节点日志（200 行封顶，最新在下），并同步进入 **Write 窗口**（见下）。
- 脚本与工程一起保存；`examples/` 有一组可运行示例（心跳波形、延迟应答、信号监视、嗅探转发、错误监视、派生信号、系统变量联动），全部随语言回归测试保持可编译。
- **节点角色**：DBC 声明的**每个节点**（不限发送节点）都在 Network 里带三态角色声明——**模拟**（允许本工具以该 ECU 名义发车：名下报文按 DBC 声明的周期进入生成器，逐条可调）、**监听**（节点在总线上只收不发，零成本；接真实硬件后其流量来自真实节点）、**离线**（节点不在仿真总线上，报文留给回放块或真实节点；未声明的节点一律离线，restbus 无需配置）。选择器下方有当前角色的说明。**角色只是闸门**：它决定"允许不允许发车"，条目发不发还看生成器里逐条目的 On 开关（见交互式生成器节）——切换角色不改写开关，激励与载荷原样保留。

## 总线与数据库（Buses 窗口）

- 一条总线可挂**多个 DBC 文件**：主库之外可再附加若干个（拖放 DBC 到窗口 = 附加为扩展库；"Open..." 按钮替换主库）。解码与查名按库序进行，重名报文先到先得。比特率（仲裁 / FD 数据段）直接输入 kbit/s 数值，失焦提交，输错回退。
- **DBC 变更自动重载**：运行中每 2 秒校验和比对挂接库，外部修改自动生效；"模拟"节点在库里**新增**的发送报文会随之出现为生成器条目（**不自动发车**——开与不开由你决定）。
- DBC 列表随工程保存（主路径 + 附加路径），相对工程目录。

## 回放块（节点详情内编辑）

- **回放块依附于节点**：从 Network 节点详情的"+ 回放块"新建（自动绑定到该节点，默认只回放它的报文），树的节点下同步出现块叶。块的**全部编辑都在节点详情里**：行首 checkbox 启用/停用、x 删除、缩进行选日志文件（.asc / .blf）与可选 id 过滤（如 `100, 3F4x`，留空 = 该节点的全部报文），Apply 提交。
- **与全局 Replay 模式无关**：回放块是仿真模式下节点的一种驱动形态，不是"回放模式"的一部分——仿真照常跑，块的流量按录制间距混入总线。
- **运行语义**：测量启动时装载日志并按过滤器归一化时间（首帧记 0），随后与发生器共用仿真时钟，按录制时的帧间距发车；同 ID 的帧会进入聚合、负载、规格与触发判定——它们就是总线流量。**仅仿真模式生效**：回放模式下整份日志本来就是信号源，块保持静默，绝无二次投递。
- 载入失败（路径无效、过滤后无帧、节点不在库中）会**停用块并就地显示载入失败原因**，绝不静默吞掉。新块默认停用——加入不发车。
- 块声明随工程保存（含启用位），恢复时立即重载队列，坏路径在打开工程时就暴露。

## 交互式生成器（节点中心）

- **节点就是编辑单元**：一个 DBC 节点的全部发车手段——**生成器条目（交互式）与脚本**——都在 **Network 窗口的节点详情**里：点开节点即见角色声明、生成器条目（完整行能力：On / 周期 / FD / Send now / 信号拖拽 / 激励）、本节点报文的 Add、响应规则，紧接着是本节点脚本列表。树形拓扑里，节点下面挂的就是它的脚本叶（`*` 运行中 / `o` 已启用 / `.` 未启用 / `!` 出错，点击打开编辑器）。
- **总览窗口瘦身**：**View → Interactive Generator** 只剩**未分配条目**（不属于任何 DBC 节点的手动条目）——搜索框、逐总线 All On/All Off 批量开关，以及**按 hex id 添加**（标准帧；扩展报文经库声明从它的节点进）。节点条目不再挤在这里。
- **角色 = 总开关，条目开关 = 自定义**：一条目实际发车当且仅当——测量运行中、所属节点角色为**模拟**、条目 On、周期非 0（事件触发条目由触发器发车）。角色切换**永不改写**逐条目的 On 开关；**新建条目默认关**（DBC 加载、重载补建、手动 Add 一律 inactive，开关状态随工程保存）；节点角色非模拟但条目开着时，面板摘要出"条启用 · 总关"、行内 chip 显示灰蓝"总关"——不发车的原因一眼可见。
- **载荷显示 = 最近一次实际发射**：行内 hex 与信号值读的是该条目**最近发出去的那一帧**（发射时算好存下，显示随消息周期跳变，不再逐帧重算）；从未发过的条目显示基准 hex。Send now 与触发 Send 同样刷新该值。
- 信号行：物理值拖拽编辑（被激励接管的信号只读，把激励改回 Constant 即解除）、激励类型下拉（Ramp / Sine / Step / Random / Triangle / Counter）、"..." 打开参数弹窗。

## 网络与角色（Network 窗口）

- **左右分栏**：窗口左侧是**树形拓扑区**，右侧是**所选节点的详情**（角色、生成器、脚本、收发信息）——选中的节点在左树里高亮，两栏各自滚动互不挤占。
- **拓扑区（TreeView）**：总线为根、DBC 节点为叶的树形目录——展开总线即见节点（默认展开）。节点行的角色色标：琥珀 ● 模拟 / 石板蓝 ● 监听 / 灰 ○ 离线（悬停有说明）；名字后的绿 ● 表示"本次运行已见到它发车"。点击节点行，右侧详情打开该节点的一切。
- **节点详情 = 节点的全部**：角色三态下拉（下方常显当前角色的说明）、Simulate all / Stop all（本总线批量切角色——注意它们只切角色，**不会**替你打开生成器条目）、**生成器面板**（本节点条目的完整编辑、本节点报文的 Add、"经硬件"开关、响应规则）、**本节点脚本**（`*` 运行中 / `o` 已启用 / `.` 未启用，点名字打开编辑器，"+ 脚本节点"新建即绑定）、**本节点回放块**（"+ 回放块"新建即绑定；checkbox 启用/停用、x 删除、就地选日志与 id 过滤）、Sent messages（实测计数与实测周期）、Received signals。一个节点发什么、怎么发、谁在发，一处看完。
- **Profile 行**：窗口顶部下拉枚举工程目录 `profiles/*.toml`，"应用"按钮一次性下发角色覆盖与硬件映射（all-or-nothing：任一总线/节点/角色词错配则整份拒绝，原因进状态行）；`[[hw]]` 全量声明——未列出的总线解挂。语义与 CLI `--profile` 完全一致——同一套工程在 simulation / bench 之间零修改切换。

## 硬件联动（Kvaser / Vector）

- **挂接**：Buses 窗口每行的"硬件"列——下拉列出本机可用通道，跨两个驱动：**Kvaser**（canlib32.dll）与 **Vector**（vxlapi64.dll，运行时加载，驱动未装则该驱动不出现条目），条目前缀 `[K]` / `[V]` 标明驱动，选中即挂接（Kvaser 波特率仅支持 10/50/62/83/100/125/250/500/1000 kbit/s 标准值；Vector 以 bit/s 直接下发）。解挂随时可做；解挂/删总线会一并清掉该总线上逐节点"经硬件"开关。
- **总线模式（Simulated / Real bus）**：工具栏 Simulation 旁的开关。Simulated（默认）下硬件**挂接保留但不收不发**——Buses 行标注"已下线"；切到 Real bus 即上线（RX 进总线，定向 TX 出线），无需重新挂接。纯仿真与真实总线通信由此一个开关分开。
- **CAN FD**：Kvaser 挂接时按该总线的 FD 数据段波特率申请 FD 能力（预设 500k/1M/2M/4M/8M 与 80%/60% 采样点；无预设匹配或硬件不支持时**降级为经典模式**并在状态行如实标注）。FD 帧经硬件发车带 FDF/BRS 标志；收到的 FD 帧的 FD/BRS/ESI 徽标照常解码。挂接状态行与 Buses 行都会显示 FD 态。Vector 首版仅经典 CAN（FD 参数接口后续迭代提供）。
- **接收**：挂接后，适配器收到的一切帧照常进总线——聚合、Trace、负载、规格、触发全部可见。**真实节点就这样进入工具**：把它的角色设为"监听"，我们不发车，只看它的真实流量。
- **发送上真实总线**：逐节点"经硬件"开关（生成器组头、节点生成器窗口、脚本编辑器里都有；仅"模拟"角色或脚本已启用且该总线已挂接时出现）。开启后该节点的发车——生成器条目、脚本 `send`、触发反应帧——**同时**上真实总线与内部总线；默认关闭——是否把模拟流量放到真实线路上，由你逐节点显式决定，程序从不自动判断。注意：真实存在的节点不要开"模拟 + 经硬件"，否则真实帧与模拟帧会在总线上叠加。
- **只收降级**：挂接优先申请收发（init access）；通道被其他程序（如 CAN King）占用时自动降级为**只收**模式并在状态行与 Buses 窗口标注。虚拟通道的只收句柄仍可发车；物理适配器的只收句柄写入会失败（帧仍进内部总线，视图不丢），此时"经硬件"开关没有线上效果。
- **与其他工具共存**：驱动的仲裁是通道级的——本工具挂接期间（哪怕只收模式），CAN King 等需要初始化访问的程序可能无法启动同一通道；反过来它们占住通道时，本工具自动降级只收。想切换工具，先在本工具"解挂"再让对方上。
- 挂接的持久化路径是 Profile 的 `[[hw]]`（见命令行与 Network 节）；GUI 手动挂接仍是会话状态。

## 触发器（Triggers 窗口）

- **条件**：信号越阈（沿触发，电平跟随该报文自身的帧，帧类与报文类一致才匹配）、ID 出现（一次运行锁存一次）、错误帧（同上锁存）、周期超时（复用规格监视的宽限判定——触发器与规格的 Dropped 判定永不打架，报文恢复后电平清除，每次掉线都是新沿）。
- **动作**：开始录制 / 停止录制 / 发送发生器条目（反应帧带触发帧的同名信号镜像，网关式转发）/ 插入标记（Graphics 画竖线）/ 清空 Trace（不影响聚合、规格与录制）。
- **触发启动的录制**自动带**预触发上下文**：文件以事件前 256 帧开头；**触发停止的录制**在边沿后再滚 32 帧（含边沿帧）才闭文件。手动录制不受影响，立即开始/停止。
- 触发求值先于一切帧处理，触发帧本身被录进文件。触发器内容随工程保存；运行态电平与计数不落盘。
- **锁存与重置**：ID 出现/错误帧条件每运行锁存一次。Triggers 窗口的 **Re-arm latched** 按钮手动重置锁存（下一个对应事件再次触发）；**清空 Trace 动作**触发时也会同时重置所有出现类条件的锁存——"清一次、等下次"。信号越阈与周期超时的电平是真实电平，永不受重置影响。

## State Tracker

- 对订阅信号的历史做**状态分段**渲染：值不变的最长区段为一条带，带内标值。
- **快速加入**：Graphics / Data 窗口左侧信号列表里**右键任一信号** → 选目标 State Tracker（或"+ 新建"）即加入跟踪，无需经过信号选择弹窗。
- 恒定贴实时边缘（回放中跟随 playhead）；时间窗宽提供 5 秒到 30 分钟的预设。
- **最小显示时长**：窗口头部 "Min ms" 输入毫秒数——更短的碎带自动并入前一段（第一段并入后一段），抖动信号保持可读；0 = 全部显示。随工程保存。
- **默认模式**：状态列表取 VAL_ 值表（显示枚举标签而非数字）或已观测数值；每个状态可钉颜色（色块 → 取色器），未钉的按会话槽位自动配色（同一值在会话内颜色稳定，超出调色板的新值哈希入位可能撞色，繁忙模拟量整体回退素色带）。
- **自定义模式**：按切分点把值轴分成区间，每区间自定义名字与颜色，规则**接管**标签与配色；删切点合并区间。
- 可见状态只有 {0,1} 时自动画成**二进制方波**（无需配置）。取色器三段式：自动 + 12 个低饱和默认色 + 完整调色板。
- **Export CSV**：导出当前窗口的状态区段表——每个可见信号一行区段（总线、信号、起止秒、时长、标签），与屏幕所画一致。无区段时提示且不写文件。
- 颜色钉住（overrides）与自定义规则随工程保存；自动槽位配色是会话状态，不落盘。

## 系统变量（System Variables 窗口）

- **View > System Variables**：CANoe 式的命名空间变量管理。表格列出 namespace、name、实时 Value（**行内可改**）、Init、Min、Max、Unit/Comment；"+ Variable" 或行内 edit 打开编辑对话框（非法输入在对话框内直接报错，不落总线），x 删除。定义随工程保存。
- **脚本访问**：`sys_get("ns::name")` 读、`sys_set("ns::name", v)` 写（语言参考有详述）。写入被夹到定义的界限内；引用未定义的变量在节点启动时报出来。
- **可观测**：每个变量发布为一条合成订阅流，信号选择树里**按 namespace 分组**——Data / Graphics / State Tracker 像选数据库信号一样选用。
- **测量开始复位**：每次 Start（虚拟或回放）所有变量回到声明的初值并重发布，观察曲线不会拖到上一次运行的尾巴。
- 值为数值型（浮点/整数通用）；改名 = 删除旧名 + 定义新名（脚本引用不会自动跟随，启动检查会报出来）。

## Write 窗口

- **View > Write**：整系统一条的滚动输出面板——节点 `print`（带 `[节点名]` 归属）、装配层 `[check]`/`[info]`、定时器与系统变量告警、节点熔断错误（红色），以及命令状态（测量启动/停止、DBC 装载、硬件挂接等，蓝色 info）。
- 每行带总线时钟戳 `[秒]`；窗口在底部时自动跟随新行，向上滚动阅读时不被拽回。顶部按类别过滤（脚本 / 信息 / 告警 / 错误）。
- **导出**把当前过滤视图写成文本文件（`[HH:MM:SS.mmm] 文本`，与窗口显示同形）——"所见即所存"；全部类别都过滤掉时拒绝导出而不写空文件。
- **清空**只清 Write 窗口自身——节点日志、测量、录制均不受影响。过滤器是会话状态，不随工程保存。

## 总线统计与规格监视（口径说明）

- **Busload** 按线上一帧占时计算：经典帧 `47+8·len` 位、扩展帧 `67+8·len` 位，FD 的载荷与 CRC 走数据段速率；位数为无填充近似。统计窗口 1 s 滚动更新，**窗口只由新帧推进**——总线静默时读数冻结，不归零。
- 错误帧单独计数并计入占时；硬件寄存器行（TEC/REC 等）在仿真模式下无意义，不列。
- **Messages / Statistics 的 Clear** 清的是逐报文计数（两窗同源）——测量照常进行，新帧到达即重新计起；总线负载与规格记忆不受影响。过滤器设置不随 Clear 重置。
- **规格监视**用逐步区间判定周期（不是运行平均，也不受单帧毛刺影响）；Export 导出的 CSV 头部带判定前提（每总线数据库路径、容差、宽限、声明周期数），正文含全部锁存违规（不受窗口过滤勾选影响）。同一报文持续违规只加深计数，不重复开行。
- 扩展帧在规格表与 CSV 的 id 列带 `ext` 后缀。

## 回放与录制

- **离线扫描（Scan）**：Replay 模式加载日志后，工具栏 **Scan** 按钮一次性把整份日志灌进聚合 / 统计 / 负载历史 / 规格 / Trace——**不用回放即可浏览全量结果**（"1 GB BLF 秒开"路线）。扫描无回放时钟、无触发动作、无节点分发、不录制；扫完自动停靠，Play 照常从头重放并重新计数（不会与扫描结果双算）。重扫从零重测。
- 回放中发生器照常可注入（日志时基为主：帧间仿真钟冻结，注入落在日志轴上；日志静默段注入随之冻结）。回放期间录制本就关闭，注入帧不落盘。
- 录制写 ASC（经典/FD/错误/远程帧）；触发启动的录制带预触发上下文与 post-roll（见触发器节）。BLF 只读。
- **BLF→ASC 转存**：`--convert <in.log> <out.asc>`——纯流式转码，不经总线与时钟，帧的时间戳/帧类/载荷原样保留。
- **预触发 / post-roll / 标记上限**：Triggers 窗口顶部可调（默认 256 / 32 / 512），随工程保存。
- **录制过滤**：工具栏录制行旁的 "id filter" 输入 hex id 列表（如 `100, 3F4x`，`x` 为扩展帧）——文件里只落这些帧（预触发上下文与 post-roll 计数同步按过滤口径）。过滤器**只管文件**：Trace、统计、负载与规格始终看全总线。留空 = 全部录制。错误帧没有 id，过滤开启时不会落文件。
- **Trace 虚拟滚动**：行缓存 + 按可视区渲染——200k 行的过滤结果也能流畅滚动/排序（内存约 18 MB 封顶；超出部分按最新优先截断并在数量上如实显示）。
- **Trace 过滤**：窗口顶部一排滤网——总线范围 / 方向 / DBC only / **payload 字节搜索**（hex 对、空格可选，如 `11 22 3F`，匹配含此序列的帧；无法解析时不过滤）/ **帧类型**（Any / Data / FD / RTR / Error）/ id 与报文名子串。过滤器只管这个窗口的显示，Trace、统计、规格仍看全总线。
- **Trace 容量与归档**：Measurement Setup 顶部的容量下拉（50k–2M 帧，随工程保存）。超出容量时最旧的帧**写入临时归档文件**（不丢失）——Trace 窗口顶部琥珀字提示"已归档 N 帧"；**Export Trace 会先回放归档再写热环**，导出的 ASC 覆盖整段运行。归档文件在系统临时目录，新运行自动清空。
- **Trace 的 Clear** 清空显示与归档——测量照常进行：录制不动、逐报文计数不动，清完新到的帧照常上屏。过滤器设置不随 Clear 重置。
- 回放支持倍速增减/直选与时间轴任意定位；暂停/恢复的边沿不产生重复帧。

## 工程与兼容性

- 工程（`.rxproj`）单文件 JSON，DBC 路径相对工程目录；30 秒自动保存。
- 旧版本工程在新版本照常加载：新增字段全部带缺省（如信号/触发器的帧类位缺省为标准帧）；未知的功能码只丢弃对应条目，不影响其余配置。
- 新版本保存的工程可能包含旧版本不认识的字段/码：旧版本读新工程时对应能力缺失但程序可用（波形状等按"丢源不丢条"约定处理）。
- 坏库容错：复用报文（mux）条件引用了消息里不存在的开关时按"无条件"放行——显示数据而不是空解码；`VAL_TABLE_` 命名表引用暂不可解析（解析器限制，有测试钉住）。
- 信号类型标记（`[u16]` / `[f32]`）按 `SIG_VALTYPE_` 声明解码位模式；can-dbc 的 0/1/2 码与 Vector 文档约定不同，以解析器为准。
