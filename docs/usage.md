# 使用说明

各面板能做什么、数字按什么口径算、出错时说什么。界面是固定的 Web 外壳
（Trace / Messages / Panel 主视图 + 右侧图表页 + 下栏），文中“窗口”指对应的 core
观测模型与标签页。
总览与快速上手见 `README.md`，脚本语法见 `docs/script_language.md`。

## 命令行（无头模式）

```
roxy-can                                  打开 Web UI（默认，127.0.0.1:2010）
roxy-can --replay <log>                   回放日志，不开窗口
roxy-can --project <p.rxproj>             无头仿真整个工程
roxy-can --check-script <f.rxcan>         校验节点脚本（flag 可重复）
roxy-can --convert <in> <out.asc>         BLF/ASC 转存为 ASC
roxy-can --kvaser-probe                   列出 canlib 可见的 Kvaser 通道
roxy-can --vector-probe                   列出 Vector 通道与总线类型；有 FlexRay 口时试开并抽取 2 秒
roxy-can --vector-probe --fibex <f>       先校验集群描述，再按它配置试开
roxy-can --vector-tx-probe <通道>         在该 CAN 口发几帧，打印驱动回的每个事件
roxy-can --export-csv <log> --out <csv>   无窗口导出信号 CSV（--dbc / --fibex 可重复）
roxy-can -h                               完整帮助
```

- **`--replay`**：`--speed <n>` 倍速（默认 1.0）、`--duration <s>` 到时即停、`--stats <csv>` 结束后导出消息统计。日志自带的 id 会让同名发生器条目不发送，不会让两个来源混在一起。
- **`--project`**：按工程里保存的条目开关与角色启动，必须配 `--duration`（仿真没有天然终点）。
- **`--profile <名>`**：叠加 `profiles/<名>.toml` 的角色覆盖与硬件映射，需配合 `--project`。全量生效——档案里没列的总线会被断开；写了不存在的总线 / 节点 / 角色词则**整份拒绝**，中止在任何发送之前。硬件打不开只进状态行，不中止（角色覆盖独立成立）。
  ```toml
  # profiles/bench.toml —— 被测件是真硬件，其余全模拟
  description = "bench rig"

  [[node]]
  bus = "Powertrain"
  node = "EngineECU"
  role = "Simulated"

  [[hw]]              # 可选：硬件映射（全量声明）
  bus = "Powertrain"
  driver = "Vector"   # 或 Kvaser，缺省 Kvaser
  channel = 0
  ```
- **`--check-script`**：编译脚本，全部通过退出码 0，任一失败非 0 并列出 `line N:M`。通过时顺带打印静态收发集合与响应映射。配 `--dbc`（可重复）与 `--node` 时，GUI 启动节点那套装配检查照跑（信号引用、发送集对照、漏实现、`set_sig` 范围）。
- 回放模式不能录制（录回放只是复刻日志）。
- release 版是控制台程序：双击会保留一个终端窗口，服务地址、启动失败原因都打印在那里。

## 仿真节点（脚本编辑器）

- 在 **Buses…** 里打开 **Scripts…** 新建脚本：选总线与 DBC 节点即完成绑定（总线跟随节点），创建后就在同一个编辑器里写代码。
- **角色是开关**：所属节点不是"模拟"时脚本一律不发送（`on start`、定时器、事件发帧全部被禁止）。未绑定脚本保持未绑定，不会被自动归到某个 DBC 节点。
- **Apply** 下发源码（测量中即时重编译重启该节点）；**运行**开关、保存/加载 `.rxcan`、节点日志都在编辑器里。
- 编辑器三栏：左栏**大纲**（每个处理器一行，点击跳转）与**收发**（静态事实表：发送集按 DBC 归属标 `*` 本节点 / `!` 他节点 / `-` 不在库，接收集、系统变量、响应映射）；中栏源码与日志；右栏**函数 / SysVar / 报文 / FlexRay** 四个插入页——FlexRay 单独一页是因为它长（一个真实集群动辄上百个槽），每行写成"`名字 (FRn)` slot N · 帧名"，点选插入 `fr_sig(n, N, "名")`，三个参数都不用另开窗口去查。输入 `Message.`、`FR0.`、`FR.集群名.`、`ETH0.`、`ETH0.帧名.` 或 `ETH.集群名.帧名.` 会自动列出名字；`frame(` 后列出 `Bus.Frame`（带空格的名字插入 `CAN1["Frame Name"]`），`frame("` / `frame(CAN1["` 内按帧名过滤；对 `let` 声明、重新赋值和函数参数里的帧实例，`.` 后补全该帧的信号。**Alt+/** 手动唤出补全（Ctrl+Space 在中文输入法下是切换中英文的快捷键，所以不用它）。
- 事件：`on start`、`on message <id>`（`*` 收所有数据帧）、`on extended message <id>`、`on fr slot <槽>` / `on fr <路> slot <槽>`（FlexRay 帧到达；不写路号就是所有路）、`on errorFrame`、`on timer <ms>`（周期）、`on timer "名"`（一次性，`set_timer` 武装、`cancel_timer` 取消）。
- `on start` 里不发帧：`send` / `fr_send` / `send_frame` 会被丢弃并在日志提示改用定时器或帧处理器。能在 CAN 目录解析的 `send_frame` 会进左侧收发表的发送集，来源写作 `<frame Bus.Frame>`；`--check-script` 同样报告。
- `frame(...)` 没写过的 CAN 信号取描述里的初始值（DBC `GenSigStartValue` / ARXML `I-SIGNAL/INIT-VALUE`），浮点信号及 FR/ETH 没有初始值时按物理 0。常量字段写入越界会在节点日志和 `--check-script` 里记 `[check]`（发送时仍夹取）。
- **FlexRay 事件里的帧上下文**：`frame_id()` 是槽号、`frame_dlc()` 是字节数、`frame_byte(i)` 读载荷、`fr_cycle()` 是这次到达的通信周期号。一个静态槽按周期相位轮流排好几帧，处理器读到的是**实际到达那一帧**。`send(frame_id())` 在这种处理器里是编译错误——把槽号当 CAN id 发出去是两套编号混用最典型的错。
- 节点会收到**自己发出的帧**：通配或同 ID 处理器里无条件发帧会自激成环，用 `frame_id()` 过滤。
- 帧处理器里用 `this` 读触发帧：`this.bus` / `this.id`（CAN）/ `this.slot`、`this.cycle`（FlexRay）/ `this.len` / `this[i]` / `this.signal("名")`；`node.bus` 是脚本自己的 CAN 通道，定时器里也能用。网关脚本因此不用硬编码触发帧的 id 或总线号。
- 编译或运行出错即**自动停止运行**，日志留原因；重新 Apply 或重启测量恢复。周期定时器错过的点收敛为一次触发。
- `print(...)` 进节点日志（200 行封顶）并同步进 Write 窗口。
- `examples/` 有一组可运行示例（心跳、延迟应答、按值分发、信号监视、嗅探转发、错误监视、派生信号、系统变量联动、FlexRay 网关）。

## 总线与数据库（Buses 窗口）

- 一条总线可加载**多个 DBC**：`Open...` 换主库（也接受只含一个 CAN cluster 的 ARXML），拖放或 `+` 附加扩展库。解码按库序进行，重名报文先到先得。
- **一次导入全部 ARXML cluster**：Buses 顶部的 `Import ARXML...` 扫描文件里的 `CAN-CLUSTER` / `FLEXRAY-CLUSTER` / `ETHERNET-CLUSTER`，每个 cluster 建自己的总线。CAN cluster 读成 CAN 路（标识符/帧类、帧长、帧→PDU、I-Signal、compu/单位、PDU 周期、ECU 端口的发送方），FlexRay/Ethernet 落在各自编号空间的下一个空索引；同一文件与 cluster 再次导入会刷新那一路的数据库，不会重复建路。多个 CAN cluster 可以共享同一份帧/PDU/信号定义，地址以各 cluster 自己的 triggering 为准；triggering 放在 cluster 外时按 `/Cluster/<名>/...` 引用归属。CAN 行的 `Open...` 可换成 DBC 或只含一个 CAN cluster 的 ARXML（会离开当前 ARXML 源）。Container/Multiplexed/Secured PDU 不在此读取范围。
- **比特率是选的不是输的**：仲裁段下拉给 `10/50/100/125/250/500/800/1000` kbit/s，FD 数据段给 `0（无 FD 段）/1000/2000/4000/5000/8000`。选错比特率不会报错，只会把整条总线的帧全部解错。工程里已存的值一定在列表里。
- **DBC 自动重载**：每 2 秒比对校验和，外部修改自动生效（测量停止时同样比对）；库里新增的发送报文会出现为生成器条目，但**不自动发送**。
- 数据库列表随工程保存（相对工程目录）。
- 窗口底部是**回放通道映射**：把日志里的通道编号指到本工程的哪一路，只有回放过的文件会出现在这里（详见「回放与录制」）。

## 回放块

- 把某节点录制日志里它的报文重新发到仿真总线上，按录制间距发送。在 **Generator…** 底部的 **Replay blocks** 新建与编辑：选日志、可选 DBC 节点、可选 hex id 过滤（如 `100, 3F4x`；后缀 `x` 表示扩展帧，留空 = 全部）。行上的 **Edit** 可改名称、总线、节点、日志和 id 过滤，Save 提交，非法 id 会就地提示。
- **只在仿真模式下生效**：回放模式下整份日志本来就是信号源，块保持静默。
- 载入失败（路径无效、过滤后无帧、节点不在库中）会**停用该块并就地写明原因**。新块默认停用。
- 声明随工程保存，打开工程时坏路径就会暴露。

## 交互式生成器

- **节点是编辑单元**：**Buses…** 的 Nodes chip 控制角色；**Generator…** 按节点分组列出条目（On / 周期 / FD / BRS / hex / 信号拖拽 / 激励），并可用 **Simulate nodes** 一次把该总线所有 DBC 节点设为模拟（只切角色，不替你打开条目）。BRS 只在 FD 勾选后可用，让数据段跑总线的 FD 数据速率；Trace 的标记显示为 `FD·B`。脚本在 `on stop` 里用 `test("name", condition)` 记录断言，停止后 Scripts 的 Tests 面板与 Write 里给出通过/失败结论。
- **Generator…** 里的**未分配条目**（不属于任何 DBC 节点的手动条目）单独列出：搜索、逐总线 All On/Off、按 hex id 添加。
- **实际发送当且仅当**：测量运行中 ∧ 节点角色为模拟 ∧ 条目 On ∧ 周期非 0。角色切换**不改写**条目开关；新建条目一律默认关。不发送的原因在行上看得见（行上的状态词显示"角色"或"MUTE"）。
- **FlexRay 槽条目跟着它的 ECU**，在 **Generator…** 里按 ECU 分组编辑。下拉只列**描述把这路里哪些帧绑给它发送**的槽；描述没说的槽就没有条目可加（状态行会点明缺的是哪一条：没加载描述 / 没调度这个槽 / 没说这帧由谁发）。本工具不推断归属，所以也没有"手工输入任意槽号"的入口。
- **FlexRay 的周期按通信周期数计，不按毫秒**：静态槽在调度表排给它的那个周期发送，能改的只有"每几个周期"，弹窗实时显示它等于多少 ms。`0 = 事件触发`在 FlexRay 不存在（填 0 会被拒绝，要它不发用 On 勾选框）。这一路没有描述（或没声明周期时间）时退回按 ms 编辑，行上的悬停说明原因。改周期数不是改调度表——槽号、相位、载荷宽度仍归描述文件。
- **载荷宽度归描述**：hex 框接受该槽声明的字节数，填少了补 0、填多了**整笔拒绝**并说明差多少（不静默截断）。
- **FlexRay 发的是本会话的流量，不是总线上的帧**：端口目前仅接收，所以生成的帧与 Panel Setpoint 的写入都从接收侧进入会话——Trace / Messages / Statistics、负载与规格、触发器、脚本、录制全都看得见，但它不出端口、也不会被另一台设备收到。面板标题与行上 chip 就这么写。FlexRay 侧没有 DBC 节点，所以也没有角色开关，条目只有 On 与 MUTE 两态。
- 回放时该槽若被日志自己带着，条目整个回放期间不发送（chip 显示 MUTE），退出回放照常。
- 行内 hex 与信号值是**最近一次实际发出的那一帧**；描述被移除后条目照旧存在并发送（行上写明"没有描述，无人解码它"）。
- 信号行：物理值拖拽编辑（被激励接管的只读，改回 Constant 解除）、激励 Ramp / Sine / Step / Random / Triangle / Counter 带参数弹窗。

## 节点与角色（Buses…）

- **Nodes chip**：Buses… 每条 CAN 总线下列出数据库节点，chip 上带该节点的生成器条目数；勾选 = **模拟**（本工具以它名义发送），取消 = **离线**（默认）。角色切换不改写条目开关。
- **Simulate nodes**（Generator… 每总线按钮）只切角色，不替你打开条目。**实际发送当且仅当**：测量运行中 ∧ 节点角色为模拟 ∧ 条目 On ∧ 周期非 0。
- **脚本**：Buses… 的 **Scripts…** 里新建脚本时选总线与节点即完成绑定；绑定后能否发送同样由该节点角色决定。脚本节点、生成器条目、回放块三类驱动并存。
- **Profile**：`profiles/<名>.toml` 的角色覆盖与硬件映射只经 CLI `--profile` 应用（all-or-nothing，错配整份拒绝并把原因写进状态行）；Web 里没有档案编辑入口，硬件连接是会话状态。
- **拓扑**：Web 不单开 Network 视图；节点按总线出现在 Buses 的 Nodes 区，条目在 Generator… 里按节点分组，实测流量看 Trace / Messages / Write。

## 硬件联动（Kvaser / Vector）

- **连接**：Buses 每行的"硬件"列下拉列出本机通道，前缀 `[K]` / `[V]` 标明驱动，**选中即连接**，`断开` 随时可做。连接与否、刚试过哪个通道，行里显示的就是那一个端口号。
- **总线模式（Simulated / Real bus）**是模拟流量是否经硬件发出的**唯一开关**。Simulated 下硬件连接保留但不收不发（行上标"未启用"）；Real bus 下 RX 进入总线，"模拟"节点的一切发送（生成器、脚本、触发反应帧）经硬件发出。想只听不发，把所有节点角色留在"离线"。
- 状态栏 `MEASURING (…)` 括号里说明**帧的走向**：`simulation`（未连接硬件）、`real bus · N`（N 条总线已连接硬件）、`simulation · hardware parked`（已连接但总线模式为 Simulated）。
- **CAN FD**：按总线的 FD 数据段波特率申请 FD 能力；Kvaser 与 Vector 都配置数据段，无匹配预设或硬件不支持时**降级为经典模式**并如实标注（Vector 会带上驱动返回的原因）。
- **USB 重新插拔后的恢复**：程序每秒检查一次 Windows PnP；设备拔出或重新插入时，会自动关闭 Vector 连接、重开 XL 驱动并刷新通道列表，不需要手动点 Refresh，重新插入后的 FD 能力也随之恢复。`Refresh channels` 仍可手动强制重扫。Kvaser 连接不受影响。
- **离线通道**：VN1610 通道按 Windows PnP 的存在性过滤（VID_1248/PID_1050），驱动留下的空名字离线记录也会被清掉；尚未建立型号映射的 Vector 设备仍以驱动配置列表为准。同型号多台设备在通道名重复时会附加 `S/N` 或 `dev N` 以便区分。
- **接收**：连接后适配器收到的一切帧照常进入总线。真实节点就这样进入工具——把它的角色留在"离线"（我们不代替它发送），它的流量照常显示。
- **仅接收降级**：优先申请收发；通道被别的程序占着时自动降级仅接收并标注。物理适配器的仅接收句柄写不进去（帧仍进内部总线，视图不丢）。
- **发送被线路拒绝不再静默**：第一次写入 Write 窗口并带上驱动给的原因，之后只累计次数，Buses 行标红 `发送被拒 ×N`（悬停读原因）。两种失败走同一句话：驱动当场拒绝写入；以及帧被接受、总线上没有节点应答（后者只出现在事件流里，行里带上驱动回报的 tag 号）。
- **与其他工具共存**：驱动的仲裁是通道级的——本工具连接期间别的程序可能起不了同一通道，反之亦然。换工具先在这边`断开`。
- 手动连接是会话状态；要固化就用 Profile 的 `[[hw]]`。
- **FlexRay 监听**：Buses 的 FlexRay 区与 CAN 那张表同形（一路一行，Name / 描述 / 速率 / 硬件 / 移除）。
  - `+ FlexRay` = 挑一份集群描述（FIBEX 2.x/3.x 与 AUTOSAR ARXML 都读，GBK 编码无碍），落在第一个没有描述的路索引上；取消则什么都不加。行集合 = 已描述 ∪ 已监听 ∪ 正在回放的日志里真有其流量；最后那种行会灰字标"日志里有这路流量"，`Open...` 就在它自己那一行。
  - **名字只是给人看的**：行末灰字 `#n` 才是这路的 cluster 索引，`FR0:13`、`fr_sig(0, ..)`、`on fr 0 slot 13`、触发规则存的数字都是它，所以改名不会影响要输入的那个编号。清空它、或重新输入 `FRn`，都等于没有名字。
  - **速率与周期只读**：FlexRay 的位时就是调度表本身，要改得改描述文件。
  - `断开` 关端口，描述与曲线全留着；行末 `x` **删除这一路**——端口、描述以及引用它槽号的一切（曲线、手动勾选行、发送条目、触发规则、规格判定）一起走，**其他各路的路号一律不动**（索引是身份不是列表位置，把后面的前移会让所有打过的数字在未提示的情况下指向另一条总线）。空出来的号下次 `+ FlexRay` 拿回。
  - 端口号与监听本身不入工程；每路的索引、名字与描述路径入工程。
  - **每路的帧只按该路自己的描述解**：槽号在两个 cluster 之间会重复，所以帧名、解码信号、调度都分 `FR{n}`。描述放错路不报错——名字与物理值都会按另一路的调度解释，看着照常，所以行上印出文件声明的 cluster 名供核对。

## FlexRay 在视图里

- **Trace**：与 CAN 帧按时间交错混排——Bus 列写这一路的名字（未改名即 `FR{n}`，知道通道时带 ` A`/` B`），ID 列是 `slot.cycle`，Name 列是该路描述里的帧名。勾 **"FR 信号"** 展开解码后的信号子行（含枚举标签）。
- **Messages** 每 **(路, 槽, 帧)** 一行：计数、周期均值 ± 抖动、末帧载荷、帧名。一个静态槽按周期相位可排多帧，所以按槽统计会让帧名每来一帧变一次；解不出帧的到达自成一"无名"行。行首 `▸` 展开后按描述顺序列出信号子行：**信号名缩进在 Name 列、物理值放在 Cycle 列、单位与枚举标签放在 Data 列**，原始值在悬停提示里；只有展开的行才解码，收起不付代价。CAN 与 Ethernet 报文同样可展开。
- **Statistics**：FR 槽位与 CAN 报文并列（计数、间隔 min/avg/max、占比）。
- **作用域**下拉有 `FlexRay: <路名>` 一档（与 `Bus: CAN{n}` 分列，因为两套编号不互解）：只看这一路，占比也算这一路的。**Manual 手动勾选的集合**同样能勾槽，与 CAN 报文共用同一份勾选集合。
- **信号可订阅**：Signals / Data / State / Monitor 都能选 FlexRay 信号，身份就是 `(路, 槽, 信号名)`。
- **录与放对称**：CANoe 录的 BLF 与 ASC 里的 FlexRay 收帧一并读入；本工具自己录的文件也写同类对象/行，录完再放回来是同一批帧。`--convert` 与 Trace 的 ASC 导出保留 FlexRay 流量。
- 负载与规格另有口径，见下面"总线统计与规格监视"。

## 车载以太网

- **数据来源**：目前只读离线 Vector BLF 的以太网对象（类型 71，按规范 + 合成样本实现，标记 experimental）；没有实时抓包与录制。
- **矩阵**：Buses 加载 AUTOSAR Ethernet 矩阵（ARXML），显示 cluster/VLAN/帧数。捕获 flow 按 VLAN、payload 长度和 IEEE1722 EtherType 打分匹配；多个候选或无候选都不猜，Name 列退回 MAC 对。`FRAME-LENGTH 含 L2 头` 是项目开关（随工程保存）：打开时按「声明长度 − 14」与捕获 payload 比较。
- **解码**：`I-SIGNAL-I-PDU` 里的 I-Signal 位偏移、大小、字节序、符号、factor/offset、单位和值表；Container / Multiplexed / Secured PDU 不在当前范围内。
- **Trace**：以太网帧与 CAN/FlexRay 按时间混排。Bus 列 `ETHn`，ID 列 EtherType，Name 列矩阵帧名（无唯一匹配时是 MAC 对）；右键可把该 L2 flow 加入本窗口的 Manual 选择。作用域多一档 `Ethernet: ETHn`。
- **以太网目前只收不发**：Buses 的 Ethernet 区只列已加载的路、簇与帧数；帧与 flow 的明细在 Trace / Messages / Statistics 中查看（EtherType、匹配到的帧名、解码信号），信号可订阅画曲线。Panel Setpoint 的 Ethernet 写入只注入本会话：使用矩阵的 VLAN、声明的 EtherType（没有则 `0x88B5`）与固定的本机管理 MAC，不出端口、不录制。
- **Messages / Statistics**：每个 L2 flow 一行，MAC、VLAN、EtherType、计数与周期；CSV 导出同样包含。
- **订阅**：以太网信号进 Signals / Data / State / Monitor，身份是 `(ETH 路, 帧名, 信号名)`，随工程保存；作用域为某个 Ethernet 路或 Manual flow 时 Messages/Statistics 也按同一规则收窄。
- **回放通道映射**：抓包工具的以太网 channel 有单独一张表，先映射到工程的 `ETHn` 再匹配矩阵、解码和聚合。
- **导出**：Trace 窗口的 Export 按扩展名选格式——`.asc` 写 CAN/FlexRay；`.pcap` 写经典 PCAP（LINKTYPE_ETHERNET，保留 MAC、VLAN TPID（含 0x88A8）、EtherType 和载荷，不写 FCS；经典 PCAP 没有方向位，Rx/Tx 都按线上帧导出）。Messages/Statistics 的 CSV 里以太网行把 EtherType 放在 `id` 列、VLAN 写进 `name` 列。

## 触发器（Triggers 窗口）

- **条件**：信号越阈（沿触发）、ID 出现、错误帧、周期超时、FlexRay 帧到达（按路 + 槽）、FlexRay 信号越阈、系统变量越阈。CAN 与 FlexRay 的条件形状一致。
- **动作**：开始 / 停止录制、发送发生器条目（反应帧可镜像触发帧的同名信号）、插入标记、清空 Trace。
- **触发启动的录制**自动带预触发上下文（默认事件前 256 帧）；**触发停止的录制**再滚 32 帧才闭文件。手动录制立即开始/停止。顶部可调预触发 / post / 标记上限，随工程保存。
- **锁存**：ID 出现 / 错误帧 / FlexRay 帧到达这类"出现"条件每次运行只锁一次。**Re-arm latched** 手动重置；**清空 Trace** 的动作也会顺带重置所有出现类锁存。信号越阈与周期超时的电平不受影响。
- 触发器随工程保存；运行态电平与计数不写入文件。

## Signals（曲线）

- **两条游标 A/B**（工具栏 **Cursors**）：双击图面放下一个（两条都在了，双击移动离得远的那条），按住游标线拖动微调。右上角读数给 `A`/`B` 两个时刻与 **Δt**（自动换单位，B 在 A 前就读负数），下面每个 **Plot** 或 **Read** 信号一行 `名字 A值 → B值 Δ差值`。游标值取该时刻**之前最近一个采样值**（报文保持值），不回退、不做线性插值。
- **采样点**：缩放到采样较稀的窗口时，曲线上会直接画出每个样本点；采样密集时只画线（或 min/max 包络），避免糊成一片。点用于看清报文更新/阶梯落在哪里。
- **Y 轴模式（按信号）**：在左侧信号名栏右键 → **Y: Auto / Y: Memory / Y: DBC range**。**Auto** 跟随当前时间窗口自动缩放；**Memory** 记住本次运行中该信号见过的所有极值，范围只扩不缩；**DBC range** 按该信号通信定义声明的 min/max 缩放，没声明范围时回退 Auto。每个信号独立选择，随 workspace 保存；Overlay 归一化视图不使用该设置。
- **Read 信号**：Signals 选择器里每个信号都有 **Plot / Read** 两段式模式开关。Read 只订阅、不画 lane，读数表按需出现：没有游标时只有 **Live values**（列头 `Now`），且只在 Signals 全屏时显示；有游标时切到游标值，A/B 时一起显示 A/B/Δ 与区间统计。点当前模式可取消，切换另一段直接换模式，Ctrl-click 信号名也能切换 Read。图上一个 lane 都没有时仍可拖游标读数，Read 集合随工程 workspace 保存。
- **读数表占用**：非全屏且没有游标时不显示读数表，图表占满图表面板，避免 Live values 挤掉曲线；放下游标后才在图下方出现游标表（双图分栏时不显示）。全屏时读数表始终存在并变成左侧竖栏，信号名与 A/B/Δ 值同行紧挨，图表占右侧。
- 游标记的是**时间**：平移、缩放、实时推进都让线跟着视图走，标的点不动；跑出视野的游标不画线，时刻仍留在读数里。没打上的那条印 `-`，没有样本的时刻也印 `-`——不把 0 当成一个读数显示。
- 游标位置与 Read 集合保存在 Web workspace 里，随工程保存恢复。

## Panel（操作页）

- 画布上方是页面标签栏：点击切换页面；Edit 下 `+` 新建空页、**Duplicate** 复制当前页、**Delete** 删除当前页（至少保留一页），双击页名就地重命名。每页有自己的画幅尺寸和控件，切换页面会清空选区、撤销历史和剪贴板，但保留 Edit 模式。
- 顶栏 **Standard / Panel** 进入操作页：固定画布默认 **1280×720**，始终显示 **8px 网格线**；画幅 W×H 在未选中控件时显示于右侧 Panel 属性，按 8px 取整，缩小到会把控件挤出画布时会拒绝；窗口不够大时画布出现滚动条，不缩放、不重排。
- **Edit** 进入编辑：右侧属性栏常驻，点控件显示控件属性，点空白显示 **Panel** 属性（画幅 W×H 与控件数），切换选区时画布宽度不变。**+ Add** 菜单添加 Button / Value / Bar / Gauge / Lamp / Toggle / Setpoint，拖动控件移动、拖右下角缩放，位置和尺寸实时吸附网格；最小尺寸按类型，重叠的落点会被拒绝。编辑时控件不触发动作。编辑时也可用右键菜单：控件上是 Duplicate / Copy / Copy signal key / Delete，空白画布上是 Paste、添加各类控件与 Undo/Redo，页签上是 Rename / Duplicate / Export / Delete；菜单支持 ↑/↓/Home/End 与 Esc（只关菜单，不退出 Edit）。
- 选中控件后右侧属性栏按类型编辑：**Button** 的 **On click** 三选一：**Write signals** 只应用下面 **Signal writes** 里的「信号 + 值」（逐项写入，失败项列在状态行，其余继续）；**Send message** 按一次发一条报文：**CAN** 选 **Bus** 和 **Message**——**Raw frame** 手填 **ID (hex)** 与 **Extended**，或直接选目录报文（自动带出 ID/Extended，此时两者只读，并出现 **Mode: Raw / Physical**），写 0–8 或 12/16/20/24/32/48/64 字节 **Data (hex)**，Raw frame 仍可发 DBC 之外 ID；**FlexRay** 选 Bus、填 **Slot**（1..2047）与 hex 载荷，按该槽声明长度补齐，只进本会话；**Ethernet** 选 Bus、矩阵 **Frame** 与 hex 载荷（选择帧时会预填对应长度的零），长度必须与帧声明一致，只进本会话；FR/ETH 命中目录帧时同样出现 **Mode**，可从 **Raw** 切到 **Physical**，按目录列出的信号填物理值（未填的取声明初始值，写出时按范围夹取），Raw 仍用 hex 载荷；**Script action** 填动作名，可再填 **Argument** 随点击发送。启动/停止/暂停等仿真控制使用顶部工具栏，不再做成面板按钮；需要“先写后做”的逻辑请写进脚本；**Value** 填 Source（信号 key、`derived:Name` 或 `sysvar:ns::name`）与小数位，只读显示实时值；**Bar / Gauge** 填 Source、最小值/最大值与小数位，按比例填充并同样可用 **Color bands**；**Lamp** 填 Source、点亮阈值（Lit at or above）与点亮颜色，源值达到阈值时亮起；**Toggle** 填系统变量名，显示 ON/OFF 并写 1/0；**Setpoint** 先选 **Target**：**System variable** 填变量名、小数位与步进（Step），输入后按 Enter/失焦写入并按 SysVar 的 min/max 夹取；**Signal** 填目录里的信号 key（CAN、FlexRay 或 Ethernet），显示该信号**在总线上的实际值**，输入后按声明范围夹取（没有声明范围就不夹取）：CAN 写进该信号的发送帧并摘掉原来的波形驱动以保持该值；FlexRay 与 Ethernet 只在本次测量内注入一帧（FR 端口仍只收、Ethernet 没有发送端口），悬停提示标注 session only；派生信号会提示不可写。两种 Target 都可选 **Script action**，在写入后再带值触发脚本；Signal 的悬停提示同时给出总线实际值与 written 写入值，控件会把该信号以 **Read** 方式订阅用于回读，删除控件或改绑后自动释放它添加的订阅，不影响你手动 Plot/Read 的选择。**Color bands** 在所有只读控件上一致：按升序添加上限（`≤`）并为每段选 Neutral / OK / Warning / Critical，可再加一条 `above` 兜底最高段，只改数字/填充颜色、不改卡片底色。属性栏里的 **Duplicate** 与 **Delete** 复制/删除控件。旧页面里的 Numeric / Setpoint 会自动迁移为 Target 对应的 Setpoint。
- 页面文件：Edit 下 **Export** 把当前页下载成 `.rxpanel`（带格式与版本，不含控件 id），**Import** 在浏览器里读取文件并作为新页面追加（名称自动去重）。导入严格校验画幅、控件类型、最小尺寸与重叠，任何一条不合格都给出提示且不改动现有页面。
- 编辑快捷键：**Ctrl+C / Ctrl+V** 复制粘贴（自动找空位并选中副本），**Ctrl+Z** 撤销、**Ctrl+Shift+Z** 或 **Ctrl+Y** 重做（工具条也有 Undo/Redo），**Delete** 删除选中控件。不做手动微调与对齐工具——位置、尺寸一律吸附网格。
- 控件会表达可用性：未测量时 Start/Stop 等按钮自动禁用并在悬停提示原因；脚本动作只在有运行中的同名处理器时可用；Setpoint 的 SysVar target 需要已定义变量，Signal target 只在测量中且信号在目录里时可用（派生信号提示只读）；未绑定或指向未知对象的 Value/Toggle 显示占位并提示原因。
- **Fullscreen** 让 Panel 盖住顶栏和状态栏，但仍保持浏览器窗口；画布按当前尺寸居中，不缩放。`Exit` 或 Esc 返回；编辑时 Esc 先清选中/退出编辑。
- 画布尺寸、控件坐标（按格）与绑定随 Web workspace 存进工程；View 模式下按钮直接执行绑定动作。

## State Tracker

- 对订阅信号的历史做状态分段：值不变的最长区段为一条带，带内标值。
- Signals / Data 左侧信号列表里**右键任一信号**即可加入某个 State Tracker。
- 恒定贴实时边缘（回放中跟随播放头）；时间窗 5 秒到 30 分钟预设；**Min ms** 把更短的区段并入前一段（0 = 全部显示）。
- 默认模式取 VAL_ 值表标签（显示枚举名而非数字）；每个状态可固定颜色，未固定的按会话槽位自动配色。自定义模式按切分点分区间，每区间自定义名字与颜色。
- 可见状态只有 {0,1} 时自动画成二进制方波。
- **Export CSV** 导出当前窗口的区段表（总线、信号、起止秒、时长、标签），与屏幕所画一致。

## Monitor（轻量监控面板）

- 右侧 **Monitor** 标签页：一行一个信号 `[状态点] 标签 值 单位`，从与 Data/Signals 同一棵选择树里挑（数据库信号 / 派生信号 / 系统变量通吃）。
- 每行可开一条阈值规则（`>=` 或 `<=` 时整行换色），行内改阈值、切方向、点色号换色。
- 行随工程保存（键、标签、小数位、规则全部写入工程）；Clear 清空，单行 `x` 删除。

## Variables（系统变量与计算通道）

- **Variables…**（原 SysVars…）：全局变量窗口，两个页签——**System variables** 与 **Computed channels**。定义都随工程保存，不依赖 Signals 页签当前画了什么。
- **System variables**：CANoe 式命名空间变量。表里列 namespace、name、实时值（行内可改）、Init、Min、Max、单位/备注。
- **Computed channels**：表达式派生通道（`[signal]`、`[CAN1:signal]` 或已有计算通道），参考列表来自整个 catalog 加已有计算通道；同名信号在不同总线时建议显示为 `CAN1:...` / `CAN2:...`，同一路内两个报文重复同名时用 `[CAN2:WheelInfoIEEE:signal]` 这类“总线:帧:信号”形式区分，帧名或 hex ID（`0x0C7`）都接受。State 色段仍在同一页编辑。
- Signals 选择器的 **Computed** 分组列出已有计算通道，**Manage…** 回到 Variables 的 Computed 页；曲线工具栏 **Channels…** 也是同一入口。
- 脚本用 `sys_get("ns::name")` / `sys_set("ns::name", v)` 读写系统变量；信号用 `报文名.信号名`（非标识符名字用 `报文名["信号 名"]`）读取。写入被夹在界限内；引用未定义的变量/报文/信号在节点启动时报出来。
- 每个系统变量发布为一条可观测流，信号树里按 namespace 分组；计算通道同样进入曲线、Monitor/Data/State、Triggers 与脚本 `derived("Name")`。
- 每次开始测量所有系统变量回到声明的初值。值为数值型；改名 = 删旧 + 建新，脚本引用不会自动跟随。

## Write 窗口

- 下栏 **Write** 标签页：整系统一条滚动输出——节点 `print`（带归属）、装配检查 `[check]`/`[info]`、告警、节点停止的错误（红）、命令消息（蓝）。
- 每行带墙钟时间戳；停在底部时自动跟随新行，向上滚动阅读时不被拽回。顶部按类别过滤。**导出**写当前过滤视图（与屏幕同形）；全被滤掉时拒绝导出而不写空文件。**清空**只清这个窗口，不动测量与录制。
- **状态栏只留最后一条，这里才是记录**：步进中出现的新消息（回放到达末尾、触发命中、post-roll 结束）与前端的失败（工程读不到、导出失败、描述装载失败）都同步写入 Write。
- 打开缺文件的项目时，状态栏只说"loaded · N 项未能载入（Write 窗口有明细）"，逐条原因（红色）在 Write 里——能恢复的部分照常恢复。

## 总线统计与规格监视（口径）

- **Busload** 按线上一帧占时算：经典帧 `47+8·len` 位、扩展帧 `67+8·len` 位、FD 的载荷与 CRC 走数据段速率（位数为无填充近似）。1 秒滚动窗，**窗口只由新帧推进**——总线静默时读数冻结，不归零。错误帧单独计数并计入占时。
- **FlexRay 的静态段占用**单位是槽不是长度：一帧占用的介质时间 = 该路描述的 `静态槽长 × 宏 tick`（载荷 24 字节还是 254 字节都一样）。两点边界：动态段不计入；没有加载描述或没声明槽时长时**只数帧、不报占用率**（显示 `-`，而不是无依据的 0 %）。
- **Clear**（Messages / Statistics）清的是逐报文计数，两种总线一起清；测量照常，负载与规格记忆不受影响，过滤器不重置。
- **规格监视**用逐步区间判定周期（不是运行平均，也不受单帧毛刺影响）。四类判定：**Unknown**（库里没这个 ID / 这路描述排不出这一帧）、**Dlc**（长度不符）、**Cycle**（周期漂移超容差）、**Missing**（静默超过宽限）。同一报文持续违规只加深计数，不重复开行；Export 的 CSV 头部带判定前提。
- **FlexRay 走同一套判据，前提换成调度表**：Unknown = 到达的槽/相位在这路描述里排不出帧；Dlc = 实到载荷**短于**声明长度（长于不算，槽载荷定长，帧名之外的填充不是错）；Cycle = 实测间隔偏离"**周期重复数 × 这一路的通信周期**"（那个 ms 数就在 Buses 行上）超容差；Missing = 原本在到的帧静默超过宽限。
- 扩展帧在表与 CSV 的 id 列带 `ext` 后缀。

## 回放与录制

- 回放按时间戳顺序调度，**不提供进度条随机跳转**（CANoe 的录制模式同样如此）：进度条只跟随不回跳，要向后赶用 **as-fast-as-possible**（一次读到日志末尾）。倍速可增减可直选；暂停/恢复的边沿不产生重复帧。
- **前向导航**：Replay 行可设步长（10 ms–5 s）并按 **Step** 立即前进；**Play for** 从当前位置播放指定日志时长后自动暂停；**To** 输入绝对日志时间（秒）并 **Go**，播放到该时刻后暂停。三种都走正常回放步进，统计/观察器与连续播放一致；目标在播放头之前会被拒绝（向前有效）。
- **别人的日志靠编号对上**：日志里每条帧只带一个通道**编号**，那是录它的那个人工程里的编号，文件里没有总线名可对照。跑起来之后 Buses 窗口底部的**回放通道映射**会列出这个文件里有哪几路、各带多少条（CAN、FlexRay、以太网各一张表），每行下拉指到本工程的某一路，或选**不回放**。改动立即生效（已经进 Trace 的帧不动），随工程保存。
- 编号在本工程对不上任何一路的 CAN 通道**不再冒充第 n 路**：以前它以 `CAN3` 的名义出现在 Trace 里又解不了码，看着像总线对上了。现在它先被挡在门外，状态行说一句（每个通道只说一次，同时进 Write 窗口），映射表把它的条数照列，等你指过去。FlexRay 一侧照旧——没有描述的 cluster 号也照常进 Trace，Buses 的行上标"日志里有这路流量"。
- 回放中发生器照常可注入（落在日志时基上；日志静默段注入随之冻结）。回放期间不录制，注入帧不写入文件。
- **录制后端随扩展名**：`.asc` 写 ASC，`.blf` 写 Vector 二进制容器（经典 / FD / 远程 / 错误帧，FlexRay 收帧一并写）。
- **边录边写**：文件在录制过程中就在增长，不用等停止。中途打开它就能读到已经录下的部分，进程被中止也不会把整段丢掉。
- **录制位置**：Record to 框只填**文件名**（默认 `record`，自动加日期后缀），存到打开工程的 `Record/` 下；填绝对路径则按它保存；没开工程时落到程序工作目录。开录时状态行显示完整路径。
- **录制过滤**同时认两套编号：CAN 写 hex id 列表（`100, 3F4x`，`x` 为扩展帧），FlexRay 写 `FR<路>:<槽>`（如 `FR0:13`，路号是行末那个 `#n`，改了名也照旧用编号）。这个框列的是"要留什么"，不是"关掉哪条总线"，只写写了槽号不会让 CAN 一侧停止发送。过滤器只管文件，Trace / 统计 / 负载 / 规格始终看全总线。留空 = 全录。错误帧没有 id，过滤开启时不落文件。
- **BLF→ASC 转存**：`--convert <in> <out.asc>` 纯流式转码，时间戳 / 帧类 / 载荷原样保留。

## Trace 窗口

- **虚拟滚动**：几十万行也能流畅滚动与排序。容量下拉 50k–2M 帧（随工程保存），**上限按帧行计**——展开的信号子行不占额度，所以展开与否看得见同样多的历史帧。超出容量时最旧的帧写入临时归档（不丢），窗口顶部提示"已归档 N 帧"，**Export Trace 会先回放归档再写热环**，导出的 ASC 覆盖整段运行；文件名选 `.pcap` 时导出以太网热环（以太网没有归档）。
- **过滤**：总线范围 / 方向 / 仅 DBC / payload 字节搜索（hex 对，如 `11 22 3F`）/ 帧类型 / 文本（id 或报文名子串）/ 时间范围（两个秒数框，留空 = 不限）/ 信号值条件（`Name>10`，运算符 `> >= < <= == != =`）。只管这个窗口的显示。
- **文本过滤的字段语法**：空格分隔、全部满足；裸词仍是原来的 name/bus/addr/id/data 子串搜索（含方向 `tx`/`rx`）。可用 `id:1AB`（hex，也认 `0x1AB`）、`bus:CAN1` 或 `bus:0`、`dir:tx`、`name:RPM`、`data:A00F`、`addr:slot`、`kind:fr`；前缀 `-` 表示排除（`-tx`、`-id:1AB`、`-error`）。带空格的值用双引号括起（`name:"Engine Status"`）。未知字段退回普通子串，不静默清空。
- **过滤时保持位置**：改文本或筛选条件时，选中行若仍匹配就保持选中；视口跟着过滤前顶部可见的帧（选中行在视口内时跟选中行），不回到最新一行。锚点帧被过滤掉时从结果头部开始，清空条件后选中行会重新出现。
- **`筛选 ·N`**：payload / 帧类型 / 仅 DBC / 时间范围 挤在可折叠行里，行收起时条件照旧在生效——所以按钮上写明此刻真在生效几条，悬停点名是哪几项（填了但解析不出来的不算）。行右键 **Clear filter** 一次清除全部条件，**唯独不动 Manual 手动勾选的集合**（那是你一条条勾的名单，不是一时输入的过滤式）。
- **精确地址**：普通文本是子串搜索（`13` 同时命中槽 113、槽 130 和名字里带 13 的帧）。只要这一个地址就写前缀：`id:1AB`、`id:1ABCDEFx`（29 位扩展帧）、`slot:13`（十进制）。两套编号不互解。行右键 **Filter this ID** 写的就是精确形式。**输入不完整时不猜测**：`id:` 后不是 hex、`slot:` 后不是合法数字时，整串按普通子串处理（表里通常就空了，改一个字符即恢复）。
- **信号值条件两种总线都算**：CAN 行问 DBC，FlexRay 行问这一帧在自己那路描述里解出的物理值——与曲线上画的、展开子行里印的是同一个数。这一帧没这个信号或这路没有加载描述，该行不出。多个条件是"且"。
- **点一行就是"这一行"**：左键点任一行，该行亮蓝底（与错误行、游标底色互不遮挡，同一行可以同时是"选中的"和"被标记的"）。表头提示 `已选中一行 · ↑/↓ 换行 · Ctrl+C 复制该行`。↑/↓ 按屏幕行序走（新行在上，所以 ↓ 往旧的方向），一个展开的 FlexRay 帧算一步（子行跟着父行一起亮、一起跳），到底就停住，不会把选中清掉；选中的行因过滤或裁剪不在了，下一次按键从当前最新一行重新落地。Ctrl+C 复制该行，八列与表格一致。两个键只在指针停在本窗口、没有输入框在打字时接管。
- **表里的两条游标 A/B**：行右键 → **Set cursor A / B** 把游标落在这一行的时刻（两种总线都放，一次右键只动一条），被标的行带底色（A 琥珀、B 青蓝，与 Signals 同两色），表头读 `A … B … Δt +221.433 ms`（时刻给到微秒）。**Clear cursors** 只在有东西可清时出现。
- **Clear** 清空显示与归档，测量照常进行（录制与逐报文计数都不动），过滤器不重置。
- 时间范围两框、过滤行是否展开、FR 子行是否展开、选中与游标位置：前三样随工程保存，后两样是会话状态。
